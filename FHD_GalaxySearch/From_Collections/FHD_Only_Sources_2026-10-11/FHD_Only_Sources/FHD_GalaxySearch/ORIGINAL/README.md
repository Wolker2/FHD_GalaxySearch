# FHD_GalaxySearch 0.1 — прототип интерфейса поиска на галакарте

**Назначение:** открыть поиск непосредственно на форме `Galaxy`, вводить начало названия системы (`В` → `Ве` → `Велес`), выбирать совпадение и устанавливать отдельную анимированную метку. В этом же окне кнопка **«Очистить метку»** удаляет только поисковую метку. Кнопка с крестиком рядом с полем очищает только введённую строку.

## Установка
Скопировать папку `Mods/FHD_MODS/FHD_GalaxySearch` в такую же папку игры и включить мод. Не заменять файлы FHD_QuestMarker. Ищите кнопку с буквой «i» справа от существующих кнопок нижней полосы галактической карты.

## Как работает
- Использует встроенные `GalaxyStars`, `GalaxyStar`, `StarName`, `lowercase`, `substr` и событие `OnKey`. Каждый ввод с клавиатуры повторно фильтрует системы по началу имени без постоянного игрового цикла.
- Показывает восемь совпадений на страницу; стрелка справа от нужного имени ставит метку. Страница меняется нижними стрелками.
- Изображение `GNPoQ.gai`, кнопки `2Tips*.gi` и `Del*.gi` взяты из предоставленного `FHD_QuestMarker_Preview_0.3.8.rar`, но имеют независимый путь кэширования и имя маркера `FHDGalaxySearchMark`.
- Очистка не затрагивает маркер заданий QuestMarker.
- Только файлы BlockPar/CacheData и графика. Не требует Xeno или native DLL.

## Важно: статус проверки
**Это сборка для тестирования, а не проверенный в запущенной игре мод.** Структура и сборка DAT проходят тесты, но интерфейсный обработчик `OnKey` в кастомной форме и порядок обновления текста поля `Edit` не проверены на работающей игре. В зависимости от порядка обработки клавиатуры возможна задержка списка на один введённый символ; для этого потребуется дополнительная правка при наличии игрового лога/результата. Не заменяет рабочую версию QuestMarker.

Тестовая версия ориентирована на SRHD 2.1.2500 и разрешения от 1024×768; окно центрируется с учётом реального разрешения.

## Исходники
`SOURCE/CFG` — все текстовые оверлеи; `SOURCE/build.py` — повторная сборка 3 DAT, стандартный Python 3.11+. Исходник компилятора — `SOURCE/Tools/compile_srhd_dat.py`.


### v0.1.6 — адаптация к GalBigGalaxy

Поиск продолжает перебор `GalaxyStars()` и `GalaxyStar(i)` из текущего сохранения,
без лимита количества систем. Для установки метки используются реальные координаты
системы, масштабированные по текущим `Constellations.GalaxySizeX` и
`Constellations.GalaxySizeY` через штатную `CT()` из объединённого Lang.dat.
Это автоматически учитывает GalBigGalaxy (400×280, до 300 звёзд), а также
ванильные размеры; при недоступных параметрах сохраняется старое значение
по умолчанию (150×100). Все кнопки, окно поиска, рамка и очистка неизменны.
